THEOLOGY FLASHCARDS — TASK 1 APP SHELL

This version includes:
- Swipe left for missed
- Swipe right for correct
- Tap to flip
- Pronunciation displayed on the front
- Text-to-speech pronunciation button
- Definition, DTS Perspective, and Memory Trick on the back
- Module selector
- Review missed mode
- Due today mode
- Spaced repetition
- Progress saved in the browser
- Offline-ready PWA files

HOW TO OPEN
1. Extract the ZIP.
2. Open index.html in a browser.
3. For full offline/PWA behavior, host the folder on any simple web host.

This shell currently contains 6 sample cards. The next phase is importing the first complete 25-card module.
